# genconwishlistvisualiser
Creates a visualisation of a Gen Con Event Wishlist, so that you can see how event priorities will interact. The intention here is to make it easy to see those circumstances where one event 'blocks' others, so that they can be ordered in a way that allows for backup events.

## Background
This is designed to use streamlit as a front end, and in this state is built to *not* require any login or authentication details from a user's Gen Con account. This made it easier to construct on a tight timeframe, but also avoids any security issues with passwords.
